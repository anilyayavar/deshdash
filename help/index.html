Overview

DeshDash is a free, browser-based tool for creating professional India choropleth (shaded) maps from your own state-wise data. It's hosted online at anilyayavar.github.io/deshdash — just open the link, no sign-up or installation required. Everything — the map library, India's boundary data, and all rendering logic — is bundled into the page itself, so once it has loaded, it keeps working even if your internet connection drops.

🎨
Sequential & Diverging Scales

Choose a one-direction gradient for values that only go up, or a two-direction gradient around a midpoint for data that can be above/below a benchmark.

🎨
Trusted Color Palettes

Built-in schemes are drawn from ColorBrewer — a well-known color system designed specifically for maps, so gradients stay easy to read and colorblind-friendly out of the box.

📋
Paste or Upload CSV

Load state-wise data straight from Excel or a CSV file — auto-detects headers, delimiters, and common name variants/abbreviations.

🎯
Live Label Position Nudging

Fine-tune any individual state's label position directly from the panel — no code editing required.

🔑
Configurable Legend

Continuous gradient or discrete color-step legend, positioned and sized to fit your layout.

📁
Multiple Export Formats

Download as vector SVG, high-resolution PNG, or a standalone interactive HTML file with hover tooltips.

Launching DeshDash

1
Open the link

Visit anilyayavar.github.io/deshdash in any browser — no download, no installation, no account needed.

2
It loads instantly

The whole app — including India's map data — is bundled directly into that one page. Once it's loaded, all map-building happens locally in your browser — no data is sent to any server while you work. You'll still need internet to open the link again next time, unless you save a local copy (see below).

3
Start building

The Data tab is active by default — enter a title and your state-wise figures to begin.

💡

Bookmark the link for quick access anytime. If you want a copy that opens without needing internet at all, use your browser's "Save As" (Ctrl+S) to save the page as a local file — the saved copy is fully self-contained and works the same way.

Titles & Placement

ControlWhat it does
Title / SubtitleMain heading and a smaller line beneath it (e.g. a financial year). Leave subtitle blank to omit it.
Source / NoteSmall print at the bottom-left/right of the map — typically a data source citation and a units note (e.g. "Figures in ₹ Crore").
Title placementSee below.
🖼️ Overlay (inside map)

The title floats inside the natural blank space above Jammu & Kashmir, saving vertical space. Best for a short title with no subtitle.

📐 Above map (reserved space)

A dedicated band is added above the map exclusively for the title/subtitle, so nothing overlaps even with longer text. Use the Top padding slider to control how much space is reserved.

✅

If your title and subtitle combination looks cramped, switch to Above map placement and increase the padding slider.

Entering State Data

The data table has three columns: a status dot, the State/UT name, and its numeric value.

Status dotMeaning
🟢 GreenThe state name was recognized and matched to the map
🔴 RedThe name wasn't recognized — check spelling or try a standard abbreviation
🟠 AmberRow is empty or incomplete

Use + Add Row to add more states, or the × button on a row to delete it. State names typed here offer autocomplete suggestions as you type.

📋

Paste / Upload CSV

For larger datasets, switch from the Table view to Paste CSV or Upload CSV using the buttons above the data grid.

📋
Paste CSV

Paste two columns of data (state name, value) directly into the text box, then click Parse & Load. Supports comma- or tab-separated data copied straight from Excel.

📁
Upload CSV

Choose any .csv or .txt file — works for a simple two-column file or a wide sheet with several columns. See Upload CSV — Column Mapping below for the full workflow.

Both methods auto-detect whether the first line is a header row and skip it if so. State names can be full names, standard abbreviations (e.g. MP, WB, UP), or common alternate spellings (e.g. Odisha/Orissa, Uttarakhand/Uttaranchal, Puducherry/Pondicherry, Keralam/Kerala).

⚠️

If a state doesn't match, double-check for extra spaces, unusual punctuation, or a name DeshDash doesn't recognize yet. Standard 2-letter state codes and most common name variants are supported.

🧮

Upload CSV — Column Mapping

Click Upload CSV above the data grid to load a file. This works for any layout — a simple two-column file (state, value), or a wider sheet with extra columns, e.g. state name, population, growth rate, and literacy rate all in the same file.

1
Upload the file

Choose any .csv file with two or more columns. DeshDash reads the header row and every column's data.

2
Check the auto-detected columns

Two dropdowns appear — State / UT column and Value column — populated from your file's actual headers. DeshDash guesses both automatically (by matching column values against known state names, and picking the first mostly-numeric column), but you can change either dropdown if the guess is wrong.

3
Click Load Selected Columns

The standard data table fills in from your chosen pair of columns, exactly as if you'd typed or pasted it directly.

✅

Multiple maps from one file: if your file has several numeric columns (e.g. population and literacy rate), just switch the Value column dropdown to a different one at any time — the table reloads and the map redraws with the new metric immediately. No need to re-upload the file to compare different measures from the same dataset.

Color Scale Type

Sequential

A single-direction gradient (light → dark), best for data that only goes one way — e.g. population, income.

Diverging

A two-direction gradient around a midpoint (e.g. red → white → blue), best for data that can be positive or negative, or above/below a benchmark — e.g. growth rate vs. national average.

Each type offers a grid of built-in color schemes — click any swatch to select — plus a Custom option to pick your own gradient colors.

💡

Reverse scale flips the direction of whichever scheme is selected — useful when a "darker = worse" scheme needs to become "darker = better" for your dataset.

📐

Scale Range & Midpoint

ControlWhat it does
Auto min/maxWhen checked, the color scale automatically stretches from your data's lowest to highest value. Uncheck to set fixed Min/Max values manually — useful for comparing multiple maps on the same scale.
Midpoint slider (Diverging only, manual range)Appears below Min/Max only when Auto min/max is unchecked and the scale type is Diverging. Drag it to set where the color scale "splits" between the two diverging colors — bounded by your current Min/Max. Defaults to the midpoint of your range and stays fixed even if you later adjust Min/Max, unless it falls outside the new range.
Steps0 gives a smooth continuous gradient. Any other number (4–8) buckets the data into that many discrete color bands — often clearer for printed reports.

What to Show

Show state name, Show value, and Abbreviate name (uses 2-letter codes instead of full names) control what's printed on/near each state.

Leader Lines & Boxes

Small or geographically awkward states/UTs (Sikkim, Goa, Chandigarh, Andaman & Nicobar, etc.) can't fit readable labels inside their own boundary. DeshDash draws a thin leader line from the state's center to a floating label box placed in open space nearby.

ControlWhat it does
Show leader linesMaster toggle — if off, these states fall back to a plain inline label (may look cramped for very small states)
Line color / thicknessStyling for the connector line and its anchor dot
Label background boxToggles the rounded box behind external labels, improving legibility over the colored map
Box fill color / opacityBackground color and transparency of the label box
Border color / widthOutline of the label box — set width to 0 for a borderless box
🔠

Label Sizes & Colors

Two independent size groups exist because they're read against different backgrounds:

External Labels

Text inside leader-line boxes — small/NE states, UTs.

Inline Labels

Text drawn directly inside large states, e.g. Rajasthan, Madhya Pradesh.

Each group has separate Name size and Value size sliders. For inline labels, Auto color (contrast) automatically picks black or white text depending on how dark the underlying fill color is — turn it off to set manual name/value colors and a fixed opacity instead.

🎯

Adjust Label Position

Leader-line labels have sensible default positions, but any map layout may need fine-tuning for specific states — e.g. two neighboring labels overlapping. This panel lets you nudge any individual state's label without touching code:

1
Pick a state

Choose from the State dropdown.

2
Nudge dx / dy

dx (horizontal: negative = left, positive = right) and dy (vertical: negative = up, positive = down) — use the +/− buttons or type a value directly.

3
Optionally remove the leader line

Check No leader line (box only) for a label that floats without a connecting line — useful for tightly-packed island groups like Lakshadweep.

⚠️

Position adjustments made here are session-only — they reset if you reload the page. If you find good values, keep a note of them for future sessions.

Tips & Tricks

📊 Use discrete steps for reports

5–6 color steps rather than a continuous gradient — readers map colors to legend values far more easily.

🏷️ Keep overlay titles short

Switch to "Above map" placement for longer titles or when using a subtitle.

📐 Comparing multiple maps

Turn off Auto min/max and set the same fixed range on all of them, so colors are directly comparable across years or datasets.

🎨 Choose diverging for centered data

Whenever your data has a natural center point — national average, zero growth, previous year's value — a diverging scale communicates it better than sequential.

📁 SVG for editing, PNG for final

Export as SVG if the map will be resized or edited further; use PNG only for the final, fixed-size version.

Troubleshooting / FAQ

My state isn't matching (red dot in the data table)

Check for typos, extra spaces, or an unsupported name variant. Standard names, common alternate spellings, and 2-letter codes are all supported — try the full standard name if a shorthand doesn't match.

I changed a slider but the map didn't update

Most controls update live, but if the map appears unchanged, click ⟳ Generate / Refresh Map to force a redraw.

The legend or a label looks cut off / cramped

Try reducing the relevant font size (Labels tab), or switch title placement to "Above map" and increase the top padding to free up space.

Can I use my own state boundary data?

Not in the current version — DeshDash ships with its own built-in India boundary data. Custom boundary support, including district-level maps, is planned for a future version.
